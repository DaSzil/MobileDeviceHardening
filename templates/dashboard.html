Wireless Pairing: Android

Pair your Android 11+ device without a USB cable.

1. Go to Settings => Developer Options => Wireless Debugging.
2. Note the IP, port shown on the main Wireless Debugging screen (Connect port).
3. Tap Pair device with pairing code for the pairing port + 6-digit code.
